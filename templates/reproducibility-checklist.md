# Reproducibility Checklist

| Status | Check | Evidence Hint |
|---|---|---|
| missing | Dataset identity/version is recorded. | `dataset` |
| missing | Train/validation/test split is recorded. | `split` |
| missing | Metric definition is recorded. | `metric` |
| missing | Baseline comparison is recorded. | `baseline` |
| missing | Primary result score is recorded. | `score` |
| missing | Target threshold is recorded. | `target` |
| missing | Sample size is recorded. | `sample_size` |
| missing | Random seed or deterministic setting is recorded. | `seed` |
| missing | Code/model version is recorded. | `code_version` |
| missing | Runtime environment is recorded. | `environment` |
